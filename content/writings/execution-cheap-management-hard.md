先说今天为什么挑这个题。

最近翻到一个开源项目 Paperclip，2026 年 3 月由一个化名 dotta 的开发者放出，到 11 月中旬 GitHub star 已经过了 11 万，最新稳定版是 11 月 6 日的 v2026.1106.0。它的口号很扎人：「如果 OpenClaw 是员工，Paperclip 就是公司。」我关注的不是又一个 Agent 框架，而是它把一件我们这些独立干活的人迟早要面对的事，做成了产品：当执行已经便宜到不值钱，你手上剩下的活到底是什么。

## 它不造模型，它造公司

Paperclip 不是聊天机器人，也不是单 Agent 框架。它是 Node.js 服务加一个 React 面板，自托管，内置 PostgreSQL，一条命令 `npx paperclipai@latest onboard --yes` 就能起。

你进去做的第一件事不是写 prompt，是「创办一家公司」：定一句使命，然后招第一个 AI CEO。

它支持 Claude Code、Codex、Cursor、Gemini CLI、OpenCode、Hermes、OpenClaw，甚至一段 Bash 或一个 HTTP 接口。只要你那个东西能接收「心跳」，就能进组织架构图。它自己的说法是：能收到心跳，就算录用。

这一下把用户的位置换掉了。你不再是那个对着 AI 敲指令的操作员，你是董事会。你定使命，AI CEO 把使命拆成目标、项目、任务，往下派给 CTO、CMO，再往下派给工程师、QA、写内容的、做调研的。每个任务都挂在项目下，项目挂在目标下，目标挂在使命下——它管这叫「目标血缘」。任何一个 Agent 在干一件小事的时候，都能往上查到自己为什么干它。

## 心跳、预算、审批：管理被拆成了几个零件

真正值得抄的不是那张组织架构图，是它把「管理」拆成了几个可以单独用的原语。

第一个是心跳。Agent 每次被唤醒，都跑一遍固定清单：读身份、看计划、取任务、执行、存记忆、汇报。这解决的是无状态 Agent 的老毛病——上一个会话干到一半，机器一重启全忘了。心跳也让 Agent 不会无限跑下去烧你的 API 额度，它每次醒来就干一段，然后交账。

第二个是预算。公司级、Agent 级、项目级三层预算，用到 80% 报警，到 100% 自动暂停。每个任务花了多少钱都有记录。这不是财务功能，这是让你能回答「这个活值不值得用最贵的模型」这个功能的前置条件。

第三个是审批和原子签出。关键动作必须人点头才能往下走；同一时间只允许一个 Agent 签出某项任务，避免两个 Agent 同时改一份文件。前者是治理，后者是协作的基本纪律。

项目名字取自 Nick Bostrom 那个「回形针最大化」思想实验——一个被要求尽可能多造回形针的 AI，最后会把整个地球变成回形针工厂。一个讲治理、预算、人类审批的项目给自己起这个名字，是自嘲，也是表态：它卖的不是「放权给 AI」，是「放权之后你怎么收得住」。

## 一个人跑生意，你迟早要面对这件事

我写内容、写代码、跑贸易，三条线凑在一起，本质上就是在跑一家一人公司。前两年我关心的问题一直是「怎么让 AI 帮我把活干完」。这条流水线就是答案：判断写什么归我，渲染封面、传飞书、推线上归脚本。

Paperclip 把问题往前推了一步：当你手下有一堆能干的「手」，你干嘛？

答案是那三样东西——定目标、划预算、设审批。哪条线值得继续投时间，哪件事该停，哪个动作必须我亲自点头。这些没有一样是「执行」，全是「管理」。以前一个人跑生意，瓶颈是执行力，你缺人手；现在执行可以外包给一堆便宜的 Agent，瓶颈就搬到了你身上：你能不能把目标讲清楚，能不能给不同的活定不同的预算，能不能忍住不什么都自己干。

我给自己立的规矩很简单：一件事如果答案能从现成选项里挑出来，就该是手的活，越便宜越好；如果它要求你在一个没有标准答案的局面里做取舍，那是董事会的活，别外包。Paperclip 把这条界线写进了它的组织架构图里，成本越高的模型越往上层放。

## 但别急着注册你的 AI 公司

说句扫兴的。

Paperclip 自己列出三条劝退：只跑一两个 Agent，这套公司制度就是过度工程；匿名遥测默认开着；要 Node.js 24.11 以上。「零人公司」是个很上头的故事，但多数独立创作者手里的真实规模，是一两个 Agent 加几个脚本，不是二十个终端窗口。为了这层想象去维护一整套组织架构，纯属给自己加活。

我真正会从它身上拿走的，是那几个管理原语，不是整套公司。心跳——让每个自动化流程干完一段就交账、留下状态。预算——给每个自动化任务定个成本上限，超了就停。目标血缘——每次开一个新自动化之前先问一句，它到底服务于我的哪个目标，答不上来就别建。

这三样东西，哪怕你只写在一个几十行的脚本里，也管用。你不需要真开一家公司，才能跑好一个人的生意。你需要想清楚的是：自己到底是谁的董事会。

执行力已经是白菜价。剩下值钱的，是你决定干什么、不干什么的那部分。AI 不会替你当这个董事会——它就是被你雇来、然后管起来的那批人。
