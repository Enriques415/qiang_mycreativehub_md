11 月 25 日，GIGAZINE 发了一篇实测：开源项目 Talorys 用一条 `npx create-talorys@latest`，就能在免费 Cloudflare 账户里搭好一个私人 AI 助手——聊天、任务、记忆、笔记、定时提醒，都有。我把这篇实测、Cloudflare 11 月 18 日更新的定价页，以及一位开发者在 DEV Community 上算的账摆在一起看，发现「免费」这两个字里藏着一个更实用的问题：它不收你的钱，但它每天只给你固定次数的思考。

## 先认清你拿到的是什么

Talorys 把 Cloudflare 的四样东西拼起来：Pages 放界面和 API 中转，Workers 处理请求，Durable Objects 跑 Agent、存数据和做定时任务，Workers AI 跑模型。所有数据在一个叫 `personal-agent` 的 SQLite Durable Object 里；Worker 关掉了公开域名和预览链接，公网暴露面只有你自己的 `*.pages.dev`，密码用 PBKDF2-SHA256 哈希后存成 Cloudflare secret。没有 R2、D1、KV、Vectorize。

功能上，GIGAZINE 试了把「从大阪搬到京都」拆成五个任务、点 Confirm plan 落进 Tasks，也试了把「我住大阪」改成过去记忆后重新问现在住哪。Automations 有三类：Reminder、Task digest、AI routine。还支持 MCP 外接工具，配 Tavily / Exa 的 key 可以做网页搜索，数据能导出成 JSON。

但别误会它的定位。DEV Community 那位作者 cloned、build、跑完测试后写得很直白：这是一个带着 LLM 前端的个人记事本，不是一个替你上网办事的 Agent；22 个工具搜索的是你自己的任务、笔记和记忆。想要的如果是指挥它订票、发邮件、爬网页，得自己写工具，而每写一次工具调用，就多一次模型往返。

这个区别很重要。**市面上大量「个人 AI 助手」的宣传，卖的是前者，让人想象的是后者。**

## 把 10,000 Neurons 翻译成人话

Cloudflare 的公开规则：Workers AI 每天免费 10,000 Neurons，每日 00:00 UTC 重置（GIGAZINE 写作日本时间早九点），超出后只有升级到 Workers Paid 才能继续，价格是每 1,000 Neurons 0.011 美元。也就是说，整整一天的免费额度，按牌价约合 0.11 美元。

关键在于 Neurons 不是按次收，是按 token 收，而且输出比输入贵得多。默认模型 GLM-4.7-Flash 的价格是：每百万输入 token 5,500 Neurons，每百万输出 token 36,400 Neurons——输出单位是输入的 6.6 倍。Talorys 当前版本（v0.3.0）的默认参数是上下文 6,000、输出 1,024、最多 4 轮 Agent 迭代、每天最多 200 次 AI 请求。

DEV 作者按 Cloudflare 价目表把这三档算了一遍：短对话（约 2,000 输入 / 200 输出）一次约 18 Neurons，一天约 550 次；跑满上下文一次约 70，一天约 140 次；如果一条消息触发四轮迭代，约 280 Neurons，一天只够 **35 条消息**。

数字要打折看：他测的是 v0.1.2，本地用的是确定性的 mock 模型，mock 的 token 估算没算进 22 个工具的 JSON schema，真实调用只会更重。我自己核对了当前仓库的 constants.ts，上述四个默认值到 v0.3.0 没变。所以这更像是量级估计，不是精确仪表读数。但量级已经够说明问题了：默认每天 200 次的上限乘以满上下文约 70 Neurons 是 14,000，比免费额度还高——**应用自己的护栏，不会比平台先拦住你。**

## 免费额度是排班表，不是工资单

免费计划上超额不会扣钱，只会报错「今日额度已用完」，等到 00:00 UTC 恢复。额度耗尽后，Today、任务、笔记、项目、记忆管理、普通提醒和任务定期通知依然能用——因为它们走的是 SQLite 和 Durable Object 的 alarm，根本不碰模型。

我认为这正是设计一人公司系统时最该抄的一点：**把系统拆成不消耗智能的骨架和消耗智能的大脑。**骨架负责存取、排序、日期比较、触发、通知，永远在线；大脑只在需要判断、归类、起草的时候介入。凡是能写成一个 CRUD 或一次时间比较的动作，就别问模型。

我会照着作者给的那组设置改：输出从 1,024 降到约 400（个人助手很少需要千字回答），上下文从 6,000 降到 3,000–4,000，每日 AI 请求数从 200 降到 100——让自己的护栏先响。定时任务里的 `reminder` 和 `task_digest` 不花 Neurons，留着；`agent_prompt` 才花，省着用。应用内的用量面板是估算，每周去 Cloudflare 后台看一次真实数字。

一套系统每天能做多少次判断，是产能问题，不是价格问题。一个人跑生意，最稀缺的从来不是钱，是你在最忙那天还能不能把事想完。

## 别人的免费，不是你的成本结构

HN 讨论里有一条我很认同：在别人的免费平台上跑系统，成本始终存在，而且条件随时会变。GIGAZINE 也同时引了另一条评价——搭起来试一试非常简单。两句都对。Talorys 才一个月大，MIT 协议，星标刚过一千四，版本从 0.1.7 跳到了 0.3.0，跑得快也意味着变得快。

Cloudflare 定价页上还有一行容易被忽略的说明：一些新模型（比如 GLM-5.x、Kimi 2.6/2.7 等）必须有付费方式才能调用。今天你用免费的 GLM-4.7-Flash 跑得很好，不代表明天想换个更强模型时仍然免费。所以定期导出那份 JSON 备份，不费什么事。

我现在给自己的每条自动化线都写三个数：每天允许多少次模型调用、每次大概吃掉多少额度、超了以后系统怎么继续干活。写不出来，说明这条线还没设计完。

别问一套系统一个月多少钱。问它在最忙的那天，够不够替你把事想完。
