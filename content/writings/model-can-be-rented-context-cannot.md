11 月 19 日，前 DeepSeek V1 作者、DeepSeek-VL 项目负责人张博（Tony Zhang）在 X 上开源了 Linger，一家叫 Simplex AI 的公司做的个人 Agent。GitHub 地址在 [simplexai-labs/linger](https://github.com/simplexai-labs/linger)，几天内过了 2k star。

他给的理由比产品本身更值得看。官宣帖里他拿 PC 的历史类比：1960 年代计算是中心化的，直到 PC 把权力交到每个人手里；今天 AI 在数据中心训练，再按 token 租给你。他说智能应该是分布式的——你的上下文、你的数据、驱动它们的智能，都应该完全属于你。

这句话正好戳到我做生意的方式。

## 省 token 只是顺手，拿回上下文才是重点

Linger 的技术卖点是本地推理。自研的 PolyStrata 推理引擎把 MoE 里最常用的专家放在显存、次常用的放在内存、冷门专家放在 SSD，用时再动态搬运。按官方数据，一台 12GB 显存的 RTX 3060 加 64GB 内存，跑 125B 的 Qwen3.8-Flash-Next 能到 45.5 tokens/s；32GB 的 5090 上则号称 179 tokens/s。还有个「模型自动驾驶」，检测你的硬件后从 49 个模型、两种推理引擎、多种量化方案里自动挑一套装上。

这些数字我打个问号。有报道已经指出，性能声明来自测试条件不同的对照，模型规模、基准细节也没完全公开。开源公告阶段，别把实验室数字当成你的日常吞吐。

但方向是对的。一个人跑生意，模型本来就是可替换的零件：这个月用 Opus，下个月换个更便宜的，下下个月本地跑。真正换不掉的是积累下来的东西——客户说过什么、哪类邮件要立刻回、发票提醒晚一步会出什么事。这些一旦只存在某个平台的会话里，换模型就等于失忆，重来一遍。

## 记忆中枢，才是它想守住的东西

Linger 的核心系统叫 Another Me。它本地读取收件箱、日历、聊天记录和会议，每晚整理成一份个人 Wiki，供所有 Agent 查询。报道里提到它在长期对话记忆基准 LoCoMo 上做到 95%，超过 Mem0、MemOS 一类记忆增强系统——同样，这是官方口径，先记着，别当结论。

比基准数字更有意思的是它的主动性。它会观察信息流，按重要和紧急决定什么时候提醒你：周一收到客户要求周五前给报价的邮件，它不当场打断，等到周三早上再弹；会议时间变更，立刻通知。你纠正它一次——「这张发票上周就到了，当时就该说」——它会记下线索；同样的偏好出现两次，就自动长成一条规则：「供应商发票，立即提醒」。反过来，你连着两次忽略快递提醒，它就学会闭嘴。

这才是我想要的东西。不是又一个等我下指令的工具，而是把「我怎么做生意」这件事慢慢记下来。一个人没有团队来同步背景，所有上下文都得靠自己带；能让上下文自己沉淀、还能带走的系统，省下的是每天重复解释自己的时间。

## 不用沙箱，靠确认卡片画边界

最让我在意的，是它选的安全路线。

Linger 不做沙箱隔离。读操作直接跑；写操作——比如发邮件——弹一张确认卡片，你随时可以接管。它靠确认卡片加服务端校验来约束 Agent 的行为。

我上周刚写过外部沙箱：把 Agent 留在外面、命令送进只能看到挂载目录的环境里，把「能跑命令」和「能碰什么」拆开。Linger 走了另一条路。它不隔离环境，而是把 Agent 放在你已经登录的浏览器和邮箱里，直接复用你现成的会话和权限——省掉配置一堆凭据的麻烦，代价是边界要一条一条画在动作上。

两条路没有谁对谁错，但适合的人不一样。如果你让 Agent 跑的是代码和测试，环境隔离更实在；如果你让它处理的是客户邮件、报价和日历，确认卡片这种「每一步都看得见、随时能接手」的方式更容易接受。区别不在哪个更安全，而在你愿意把注意力花在哪：管环境，还是管动作。

## 我不急着把生意搬进去

开源、本地、不按 token 付费——这三件事凑齐，很容易让人想把整套工作流都迁过去。我不会。

性能数字等着第三方验证，主动提醒的误报率没人给过，确认卡片在一天几十次调用时会不会点到麻木，也没人试过。更重要的是，Another Me 积累的那份 Wiki 是它的护城河，也是它的锁：格式、导出方式、迁移路径，决定了我哪天能不能把上下文带走。

我要的不是又一个更聪明的助手。是当我换掉模型、换掉工具甚至换掉整台电脑时，那份关于「我怎么做生意」的记忆还在。模型能租，上下文不能。

这一点，跟它是不是本地部署没关系，跟它是不是开源也没关系。只跟一件事有关：数据最终在谁手里。
