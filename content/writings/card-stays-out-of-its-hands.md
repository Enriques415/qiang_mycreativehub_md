# 能代我付款还不够，我更在意卡在谁手里

上周五，也就是 11 月 13 日，OpenAI 发布了 [ChatGPT Wallet](https://openai.com/index/introducing-chatgpt-wallet/)。官方的说法很明确：这是第一个让 Agent 能付款、却拿不到用户真实卡号的钱包；每一笔都要经过一次安全校验。

我的判断也很简单。一个人用 AI 把生意跑起来，真正要看的不是它终于能代我结账，而是卡有没有进它手里。确认很重要，但确认之前，凭证本身就不该出现在对话里。

## 它能付款，不等于它拿着卡

ChatGPT Wallet 先从美国的 ChatGPT Pro 用户铺开，通过个人 Agent dots 来用，要年满 18 岁，并用符合条件的美国发卡行卡片。帮助文档写得很清楚，它还不在普通 Chat、Work，或单独的 Codex 线程里用。

用法并不花哨。你把卡加进钱包一次，之后可以跟它说「帮我找一件毛衣」，或「下个周末去芝加哥，帮我订酒店」。到了结账，它会让你先看商家、商品、总价、用的哪张卡，以及有没有配送或连续扣款条款，再用 Face ID 或指纹批准。[帮助中心](https://help.openai.com/en/articles/20001654-making-purchases-with-chatgpt-wallet)把这一步写得很硬：保存卡和批准一笔购买是两件事，每一次都要重新看。

批准之后，支付网络会生成一个付款令牌——一组替代的卡号、安全码和有效期。扣款仍然落在你选的那张卡上，但官方写明：真实卡号不会分享给商家，也不会分享给 Agent。收据上看到的号码，可能和实体卡不一样。

这和「把卡号贴进对话框，让它去填表」完全不是一件事。帮助文档甚至专门提醒：卡号、有效期和安全码只许填进安全表单，不要写在聊天里。对我来说，这句话比功能列表更要紧。工具一旦会替我花钱，最危险的不是它手快，而是凭证进了它能读到的上下文。进了那里，再完善的「请确认」都晚了一步。

我自己做内容，也做贸易。软件订阅、域名、样品、运费，这些支出本来就碎，也本来就适合让工具去比价、去准备结算。可碎归碎，每一笔都是真钱。我可以让它去找、去比、把结算页准备好，但卡必须停在钱包里，而不是停在某一轮对话里。

## 下一次诱惑，是预授权

OpenAI 已经把下一步写在同一篇公告里。他们预期，用户以后可以给 Agent 设好消费限额、品类或时间范围，把购买完全委托出去，并提前批准。今天还做不到，每一笔都要单独确认。

对一个人的生意来说，这句话比「现在能代付了」更刺耳。贸易上的补货、常用耗材、固定软件，很容易让人觉得：既然每次都是同一类东西，不如给它一个额度，省掉一次次点头。短时间里，这会显得很合理。可预授权一旦打开，你批准的就不再是「这一笔」，而是「这类事，在某个范围内，可以不用再问我」。

我暂时不想跨过这条线。

不是因为官方的确认设计不够看。恰恰相反，今天这套流程里有几处我愿意留下来：每次都要看总价和条款；生物识别不是随手点掉一个通知；每笔批准会留下记录；令牌替代真实卡号。这些是把付款从「对话里的一句话」变回「一次明确的财务决定」。我要的是把这一步用起来，而不是尽快跳过它。

还有一处不能含糊。帮助文档写，如果你同意了连续或循环扣款，商家可能按你同意的条款保存付款凭证，再次扣款。也就是说，你点下的那一次批准，未必只覆盖眼前这一单。取消和退货仍然要找商家，认不出的扣款要找发卡行。批准通过，也不等于订单已经生成——如果结果不清楚，要先核对商家确认，再决定要不要重试。这些听起来像使用说明，其实是在提醒：付款权交出去之后，善后并不会一并交给 Agent。

商家那边也还没有完全准备好。官方自己承认，有些网站可能会无意挡住这类购买，风控系统也可能把正当的 Agent 付款判成异常。钱包并不能在所有店里完成结账。对我这种还要和供应商、平台、物流打交道的人来说，这意味着两件事。工具可以准备购买，但最后那一公里仍然可能走不通；走得通的时候，我更不能因为省事，就把预授权先打开。

## 我留下的那条线

我并不反对让 Agent 靠近钱。正相反，一个人同时跑内容和贸易，最耗神的往往不是思考，而是那些已经决定过、却还要自己去点的支付。找到合适的工具、比三家运费、把一张该续的订阅准备到结算页，这些我愿意交出去。

但我给自己留的线很窄。

准备可以自动；卡不进对话；每一笔真钱，仍然经过我。

加卡走安全表单，不走聊天。结账用令牌，不用真实卡号。批准之前看商家、看总价、看有没有连续扣款。预授权先关掉，哪怕以后官方把限额和品类做得再清楚，也等我自己跑过一段时间，再决定要不要放开某一类小额、可撤销的支出。发布、删除、付款，本来就是同一类门：先问我，再放行。现在多出来的，是更硬的一条——问我之前，凭证就不该在它手里。

所以，我羡慕的不是它终于能替我付钱。我要的是更窄的一句话：它可以去结账，卡不必经过它。
